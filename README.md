# Robot-Framework-Practice

Practice projects for learning and applying Robot Framework across web, API, desktop, and parallel test execution scenarios.

## Projects

- **DemoBlaze_RobotTest**: UI automation practice for the DemoBlaze web application.
- **Gmail_AutoSend**: Robot Framework exercises focused on automating Gmail send flows.
- **mailAPIandUI**: Combined API + UI automation experiments around mail workflows.
- **Parallel_Pabot**: Examples of running Robot Framework suites in parallel with `pabot`.
- **DesktopApp**: Desktop application automation practice with a page-object-style structure.
